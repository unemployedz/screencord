Why this exists

Your Discord (Kettu) build is missing Discord’s iOS Broadcast Upload Extension. The system picker only shows TikTok / ChatGPT / Gemini — those are other apps’ extensions and cannot feed Discord’s stream. A Discord plugin cannot fix that.

This page is a standalone WebRTC voice/video (and screen share where the OS allows). Use two devices/browsers and exchange the offer/answer once. No Discord required.

Controls

Ready.

On iPhone Safari, screen share via browser is limited. Prefer desktop Chrome/Edge for full-display share. Voice/video between phones works.

1 · Create call (person A)

Start media, then create an offer. Send the text to the other person (chat, Notes AirDrop, etc.).

2 · Join call (person B)

Paste A’s offer, create answer, send the answer back to A.

3 · Person A finishes

Paste B’s answer here to complete the link.

How to use (2 people)

  1. Both open this same page (GitHub Pages / local file / any host).
  2. Both tap Start camera + mic and allow permissions.
  3. A taps Create offer → Copy → sends text to B.
  4. B pastes offer → Create answer → Copy → sends answer to A.
  5. A pastes answer → Apply answer. Video/audio should connect.

Local IP tip: on the same Wi‑Fi you can host this folder with python3 -m http.server 8080 and open http://YOUR_LAN_IP:8080 on the other phone. Signaling is still the offer/answer text (no extra server).
